## 攻略Wiki

**ダンジョンの入口でタクティクスでもしようよ。 攻略Wiki**

[https://makiabe.github.io/https-github.com-makiabe-dungeon-tact-wiki/?lang=ja](https://makiabe.github.io/https-github.com-makiabe-dungeon-tact-wiki/?lang=ja)

ゲーム内データをもとに、攻略情報や各種データを確認できるWikiとして構築しています。

## 主な掲載内容

- キャラクター情報
- スキル・アビリティ情報
- 装備データ
- ストーリー・ミッション情報
- イベント情報
- 敵・ボス情報
- 編成・育成情報
- 戦闘システムの解説
- 初心者向け攻略ガイド
- ゲーム内データをもとにした検索・図鑑

スマートフォン・PCの両方から閲覧できます。

## データについて

掲載しているキャラクター、スキル、アビリティ、装備、イベントなどの情報は、ゲーム内データをもとに構築しています。

ゲームのアップデートに伴い、掲載内容が変更・更新される場合があります。

攻略情報についてはゲーム内の仕様・データをもとに作成していますが、プレイスタイルや編成によって有効な戦術は異なります。
